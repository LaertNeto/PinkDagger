# PinkDagger

Extensão de navegador (Manifest V3) que adiciona a aba PinkDagger às fichas de Daggerheart no Roll20. O código fica em `pinkdagger_for_roll20/`.

## Changelog

- Toda mudança visível para quem usa a extensão (recurso novo, melhoria, correção de bug, permissão nova no `manifest.json`) deve ser registrada em `pinkdagger_for_roll20/CHANGELOG.md` **na mesma tarefa** em que a mudança é feita, sem esperar pedido.
- Escreva na seção da versão ainda não lançada, no topo do arquivo (`## [x.y.z] - não lançada`), usando a versão do `manifest.json`. Se não houver uma seção assim, crie uma.
- Use as seções **Novidades**, **Melhorias**, **Correções** e **Outros**, em português, do ponto de vista de quem usa a extensão (o que mudou e onde, não como foi implementado).
- Ao lançar uma versão, troque "não lançada" pela data (`AAAA-MM-DD`) e use o texto dessa seção como notas da release no GitHub.
- Refatorações internas sem efeito para quem usa não precisam de entrada.
